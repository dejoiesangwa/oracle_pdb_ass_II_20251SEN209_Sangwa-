# oracle_pdb_ass_II_20251SEN209_Sangwa # Oracle PDB Assignment II
## 1. Overview In this assignment, I worked with Oracle Pluggable Databases (PDBs). I did the following activities: - Created a new PDB - Created a user inside the PDB - Opened the PDB and checked its status - Created another PDB for deletion - Deleted the temporary PDB and checked that it was removed - Worked with Oracle Enterprise Manager - Took screenshots of the main steps as evidence --- 
## 2. Oracle Environment Used For this assignment, I used: - Oracle Database 21c Enterprise Edition - SQL*Plus - Oracle Enterprise Manager Database Express - Windows operating system - ORCL as my main database ---
## 3. Task 1 – Creating a New PDB In Task 1, I created a PDB called: **SA_PDB_20251SEN209** Inside this PDB, I created the user: **SANGWA_PLSQLAUCA_20251SEN209** After creating the PDB, I opened it and checked its status. The PDB was successfully opened in **READ WRITE** mode. I also checked that the user was available inside the PDB. The screenshots for this task are saved in the `screenshots/pdb_creation` folder. ---
## 4. Task 2 – Creating and Deleting a PDB In this task, I created a temporary PDB that was only used for practicing the deletion process. After creating it, I checked that it was available in the database. I then closed the PDB and deleted it together with its data files. After deleting it, I checked again to make sure that the PDB was no longer available. The screenshots for this task are saved in the `screenshots/pdb_deletion` folder. ---
## 5. Task 3 – Oracle Enterprise Manager For this task, I worked on setting up Oracle Enterprise Manager Database Express so that I could access my Oracle database using the browser. I configured the required HTTPS port and worked on connecting Oracle Enterprise Manager to my PDB. The screenshot for this task is saved in the `screenshots/oem_dashboard` folder.
